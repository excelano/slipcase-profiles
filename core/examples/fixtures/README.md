# Fixtures

Source metadata that example cases are filled from, kept outside the cases so that no case carries a member the profile does not define.

`word-core.xml` is a `docProps/core.xml` part in the form Microsoft Word writes it. `valid/from-word` holds the `[core]` table §4.1 and §4.5 of SPEC.md produce from it. Its creation instant falls on the evening of 17 January in US Central time and on 18 January in UTC, and the table carries the UTC date.
